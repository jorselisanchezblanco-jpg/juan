Preguntas frecuentes

Información útil antes de empezar.

¿Mis documentos se suben a internet?

Esta versión procesa archivos localmente en el navegador para las operaciones disponibles. Las bibliotecas de procesamiento se cargan desde una CDN externa, pero los documentos no se envían a esa CDN. Evita usar dispositivos compartidos para archivos confidenciales.

¿La compresión siempre reduce el tamaño?

No necesariamente. Los PDF con imágenes ya comprimidas o con contenido optimizado pueden reducirse muy poco o incluso no reducirse. La compresión de esta versión intenta optimizar la estructura del PDF; no recomprime de forma avanzada todas las imágenes internas.

¿La firma que agrego es una firma digital certificada?

No. La herramienta inserta una firma visual en el documento. No equivale necesariamente a una firma digital certificada ni garantiza identidad, integridad criptográfica o cumplimiento de requisitos legales específicos.

¿Puedo desbloquear cualquier PDF?

Solo debes desbloquear documentos cuando tengas autorización y la contraseña correspondiente. No se intenta eludir la protección de archivos sin permiso.

¿Por qué algunas funciones requieren internet?

La aplicación carga bibliotecas de código abierto desde una CDN. Para publicar una versión de producción, conviene alojar y fijar versiones de esas bibliotecas, añadir pruebas y revisar la compatibilidad con documentos complejos.

NubePDF es una herramienta de procesamiento de documentos. Conserva siempre una copia de tus archivos originales.
